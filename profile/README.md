# 🔐 La Salle Cyber Security Club
### *Think critically. Break things safely. Defend the digital world.*

---

## 🧠 Who We Are

The **La Salle Cyber Security Club** is a student-run community dedicated to understanding how modern systems **fail, break, and survive attacks**—and how to defend them.

We explore cybersecurity from **both sides of the keyboard**:
- 🛡️ Defensive security (blue team)
- 🧨 Offensive security (red team)
- 🧩 And everything in between

No experience required—just curiosity and a willingness to learn.

---

## 💻 What We Do

### 🔍 Learn Real Cybersecurity Skills
- Networking & internet fundamentals  
- Linux, Windows, and system internals  
- Cryptography (the math that keeps secrets secret)
- Malware behavior & analysis
- Web security & common exploits

### 🧪 Hands-On Practice
- Capture The Flag (CTF) challenges  
- Packet analysis & traffic sniffing  
- Vulnerability scanning & exploitation  
- Password cracking (ethically, legally, academically)

### 🏆 Compete & Collaborate
- Team-based cybersecurity competitions  
- Cooperative problem solving  
- Strategy, logic, and creative thinking under pressure
